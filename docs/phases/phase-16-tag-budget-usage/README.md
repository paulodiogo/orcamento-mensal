# Fase 16 — acompanhamento de orçamento por tag

## Objetivo

Exibir, na tela inicial e nos relatórios mensais, o gasto acumulado de cada tag em relação ao orçamento opcional já configurado para ela.

## Limite desta fase

Esta fase implementa a apresentação e o cálculo de consumo por tag no mês atual do dispositivo. A Home permanece sem seletor de mês e o relatório mantém seu escopo mensal. O orçamento atual da tag é utilizado; não se cria histórico mensal de versões. Não haverá tabelas, migrações, dependências, rateio, alertas ou notificações.
